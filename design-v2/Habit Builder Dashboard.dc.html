Salin template1 menit
Buka link template dari email pembelian, lalu klik Buat salinan (Make a copy). Salinan tersimpan di Google Drive milikmu sendiri.
Screenshot: halaman "Buat salinan"
2
Buka Apps Script1 menit
Di salinan sheet, buka menu Ekstensi → Apps Script (Extensions → Apps Script). Kode aplikasi sudah ada di dalamnya; tidak perlu diubah.
Screenshot: menu Ekstensi → Apps Script
3
Deploy sebagai aplikasi web3 menit
a. Klik Terapkan → Deployment baru (Deploy → New deployment).b. Pilih jenis Aplikasi web (Web app).c. Atur seperti ini:
Jalankan sebagaiSaya (email kamu)Yang memiliki aksesHanya saya
d. Klik Terapkan (Deploy).
Screenshot: dialog Deployment baru dengan pengaturan di samping
4
Izinkan akses2 menit
a. Klik Izinkan akses, lalu pilih akun Google kamu.b. Muncul layar "Google belum memverifikasi aplikasi ini".c. Klik Lanjutan (Advanced) → Buka Habit Builder (tidak aman).d. Klik Izinkan (Allow).
Kenapa muncul peringatan?Aplikasi ini berjalan dari salinan milikmu sendiri dan tidak didaftarkan ke Google, jadi Google menampilkan peringatan standar. Aplikasi hanya membaca dan menulis Sheet serta folder Drive milikmu. Tidak ada data yang dikirim ke penjual atau pihak lain.
Screenshot: layar peringatanlingkari tombol "Lanjutan" dan link "Buka … (tidak aman)"

Buka & simpan link aplikasi1 menit
Salin URL aplikasi web (berakhiran /exec), buka di browser, lalu bookmark. Kirim link ini ke HP kamu (mis. lewat email ke diri sendiri).
Screenshot: dialog "Deployment diperbarui" dengan URL

Tambahkan ke layar utama HP2 menit
iPhone · SafariBuka link → ketuk ikon Bagikan → Tambahkan ke Layar Utama → Tambah.
Screenshot: menu Bagikan
Android · ChromeBuka link → ketuk ⋮ → Tambahkan ke layar utama → Tambahkan.
Screenshot: menu ⋮

KALAU ADA MASALAH
Link aplikasi hilangBuka Apps Script → Terapkan → Kelola deployment (Manage deployments) → salin URL lagi.
Muncul "Authorization required" lagiUlangi langkah 4. Ini wajar setelah template diperbarui.
Halaman kosong atau errorPastikan kamu masuk dengan akun Google yang sama dengan pemilik salinan. Coba buka di jendela biasa (bukan Incognito).
Total ± 10 menit (target PRD < 15). Label menu Google ditulis Indonesia + Inggris karena tampilan bahasa akun pembeli bisa berbeda. Kotak abu = tempat screenshot asli; perlu diambil dari akun nyata.
